# S5 对焦研究：机主采集指南

版本：2026-11-27。适用机型：**第一代 Panasonic LUMIX DC-S5**。S5II / S5IIX 的样本请另建会话，不能混成 S5 基线。

我们需要两类证据：一类是“相机看到了谁、框跟得怎么样”；另一类是“真正拍到的画面是否合焦、对焦是否反复拉动”。先做约 15 分钟的小样本，研究人员检查通过后再扩充。本文中的次数、动作和编号是本项目的采集方案，并非松下官方测试标准。

## 1. 这次需要什么，不需要什么

准备相机、现有的可自动对焦镜头、存储卡、手机、稳定支撑，以及一个有文字或细纹理的静止物体。移动测试请找一位愿意入镜的成年人；也可以先只做静物测试。无需购买镜头、照度计或采集卡。

只使用原厂正常拍照、录像和手动对焦功能。**不用更新或刷写固件、进入维修模式、拆机或安装第三方固件。** 记录当前机身与镜头版本即可；若之后版本变化，应另建会话。拍摄前用手机记录原设置，结束后按需恢复。

| 数据 | 能告诉我们什么 | 不能据此认定什么 |
|---|---|---|
| 相机原始 RW2 + JPEG | 同一瞬间的原始照片、曝光信息和成片清晰度 | RW2 不是对焦网络收到的内部输入张量 |
| 相机原始视频 | 连续画面、主体运动、可见的失焦和恢复 | 不能假定文件里带有对焦框、内部置信度或镜头指令 |
| 手机拍摄相机 LCD 的视频 | 屏幕上可见的框、提示和操作过程 | 显示框不是人工真值，屏幕刷新时间不等于内部推理时间 |
| 手动对焦参考组 | 同一构图下可达到的较清晰结果 | “第 3 张”不是镜头编码器值，也不是精确焦距位置 |

普通机主这次**无法提供内部 DSP 张量、真实镜头编码器位置、逐帧马达命令或精确传感器时序**。这些项留空即可。照片 EXIF 或屏幕显示的距离即便存在，也不能直接改名当作实测编码器数据。

## 2. 开始前：设置与记录

先拍设置照片，不必抄写长菜单。中文菜单用词可能因版本不同略有差异，以下附英文项用于查找。

1. 拍下机身型号、机身固件版本、镜头完整型号及镜头固件版本。避免把序列号、姓名、地址一并公开。
2. 照片设为 **RAW+FINE（RAW+精细 JPEG）**，单张拍摄；不用 6K/4K PHOTO、后对焦或高分辨率模式。S5 支持同时保存 RAW 与 JPEG。[官方规格](https://help.na.panasonic.com/answers/features-and-specifications-lumix-s-series-dc-s5/)
3. 相机放稳。同一组固定镜头、焦段、机位、目标位置和构图。优先选择能看清文字、布纹或细节的平面目标，避免只拍一面白墙。
4. 使用自己熟悉的曝光操作，把静物正常曝光。记录光圈、快门、ISO；同一组尽量保持一致。不要以“调暗曝光”代替真实弱光环境。运动模糊和失焦不同，移动样本应尽量有足够短的快门；如光线不足，保留实际参数和模糊情况，不必勉强凑值。
5. 记录白平衡、照片风格、降噪/锐化、防抖开关。试采阶段不会设置就拍菜单页，不要求逐个调成特定值。

### 对焦的基线设置

下表是为减少测试变量而选定的项目基线。找不到某项时，拍下屏幕并记录“未知”，先交样本，不要恢复出厂设置。

| 测试 | 设置 |
|---|---|
| 静物照片 | 焦点模式拨杆 **S / AFS**；AF 区域 **1-Area（单区域）**，放在目标纹理上 |
| 人物移动视频 | 拨杆 **C / AFC**；AF 模式 **Face/Eye/Body/Animal Detect.**，记录动物检测是否开启 |
| 视频持续对焦 | 视频菜单 → Focus → **Continuous AF = MODE1**；**AF Custom Setting(Video) = OFF** |
| 手动参考组 | 拨杆 **MF**，用放大显示辅助判断细节 |
| 拍照触发方式 | 本方案使用半按快门；记录 **Shutter AF** 状态。习惯后键对焦者可使用 AF ON，但整组保持一致并说明 |
| 避免提前自动合焦 | 可找到时把 **Quick AF、Eye Sensor AF** 设为 OFF；不会设置则记录现状，结果不能当作严格触发延迟 |
| 弱光辅助灯 | 先拍当前状态；核心弱光测试使用 **AF Assist Light = OFF**。若额外测试开启，另起一组 |

菜单名称和拨杆位置按 DC-S5 官方说明书核对；不要套用 S5II 的相位对焦菜单。官方说明书还提示，部分弱光条件下半按时 AFC 的行为可能类似 AFS，采到这种现象应如实保留。[DC-S5 官方高级说明书，pp. 93、100、256–258、367、376](https://eww.pavc.panasonic.co.jp/dscoi/DC-S5/P_PP/DC-S5_DVQP2197ZD_full_eng.pdf)

视频选普通速度的 FHD 25p 或 30p，选一个全程保持一致，拍下编码格式/分辨率/帧率设置。不要用 S&Q 慢动作。模式盘使用创意视频模式进行视频组，照片组用自己熟悉的 P/A/S/M。本次首选手机拍 LCD：HDMI 输出可能改变连续 AF 的工作条件，不作为第一轮必需设备。[DC-S5 官方高级说明书，p. 257](https://eww.pavc.panasonic.co.jp/dscoi/DC-S5/P_PP/DC-S5_DVQP2197ZD_full_eng.pdf)

## 3. 手机与相机怎么配合

手机固定在相机后方，清楚拍到整块 LCD，尽量减少反光。画面里能看到操作快门的手指更好。手机录普通 30 或 60 fps 视频即可，记录实际帧率；不要用慢动作拍 LCD。

每条视频按下面顺序：

1. 先开始手机录像，对着手机说出编号，例如“S03，正常光，第一次”。
2. 开始相机录像。让助手在相机镜头前举一下写有编号的纸，再做一个清楚可见的动作，例如张开手掌后合拢，同时拍一下手。手机会拍到 LCD 上的同一动作；声音也能辅助配对。
3. 留约 3 秒稳定画面，再开始正式动作。结束后再留约 3 秒，先停止相机，再停止手机。
4. 记下这次相机与手机的文件名。相机时间与手机时间最好先对到相近，但**仅凭时钟相同不能保证逐帧同步**。

研究人员会用共同动作/声音对齐。LCD 和手机的显示、拍摄都有延迟，因此记录的是近似对齐；无法测出的偏移或误差填 `null`，不能填 0 冒充已校准。静物组无需额外录相机视频，一段手机录像可覆盖一整组拍照，并口述每次编号及“近端/远端”。

## 4. 约 15 分钟试采

熟悉设置后通常约 15 分钟；初次操作多花一些时间正常。先检查一张 RW2 和配对 JPEG、一个相机视频及对应手机视频确实能打开，再继续。时间不足可以先交 S01、S03 和设置照片，其余注明未采集。

| 编号 | 内容 | 最小数量 |
|---|---|---|
| `S01_static_normal` | 正常光静物，AFS，近端重置与远端重置交替 | 近端 3 次 + 远端 3 次，共 6 对 RAW+JPEG；1 段手机视频 |
| `S02_static_low` | 同一静物、机位和构图，实际降低环境照明 | 近端 3 次 + 远端 3 次，共 6 对；1 段手机视频 |
| `S03_approach_normal` | 正常光，人缓慢走近再退远 | 约 15 秒相机视频 + 对应手机视频各 1 段 |
| `S04_approach_low` | 相同路线，较暗环境 | 约 15 秒相机视频 + 对应手机视频各 1 段 |
| `S05_lateral_occlusion` | 正常光横向走动，中途短暂遮挡 | 约 15 秒相机视频 + 对应手机视频各 1 段 |
| `S06_manual_reference` | 静物手动对焦参考，正常光与暗光各一组 | 每组约 7 对 RAW+JPEG，共约 14 对 |

S06 下两种光线在记录中分开标记，例如 `normal_r01` 与 `low_r01`。不要把整份会话只标成“正常光”。如果暂时没有人物，先完成 S01、S02、S06，不用拿屏幕播放视频冒充真人实拍。

### S01 / S02：每次都重新从近处或远处对焦

目标放在容易拍清、超过镜头最近对焦距离的位置。近处和远处各准备一个临时目标，例如近处一张卡片、后方一个有纹理的物体。每次都保持主目标最终构图一致。

1. 把焦点先放到近处临时目标，可暂时用 MF 调焦；再回到 AFS。不要改变最终机位。确认主目标此时确实明显变虚，并口述“近端，第 1 次”。
2. 将固定的单区域框对准主目标纹理。松开按钮后再半按，等待相机完成对焦；随后完整按下拍照。记录等待时间可从手机视频事后估计。
3. 若约 5 秒仍不合焦，就口述“超时”，保留这一段手机录像；相机如允许拍下就保留照片，不要为了补一张而暗中改变释放优先设置。超时未生成照片也算一个有效失败事件。
4. 下一次先调到远处临时目标，再以同样方法对焦主目标。按“近、远、近、远、近、远”完成 6 次。

如果用 AF 对近/远临时物体做重置，可以拿走挡在主目标前的近卡，或先选择远处区域再把框移回主目标；不要把重置阶段误计成主目标合焦时间。记录采用哪种方法。重点是可重复的近/远起点，**不用声称起点具有精确距离或编码器数值**。

暗光组尽量只改变照明：调暗灯、关掉一部分灯或在较暗房间拍。目标仍应能辨识；不是完全黑屏。记录“台灯一盏”“窗帘关闭”等实际描述，没有照度计就把 lux 留空。相机出现 LOW 等提示时，让手机拍清楚。

### S03 / S04：走近、退远

相机固定，不跟着转。人物从较远处缓慢走到较近处，再退回去，例如从约 3 米到约 1.5 米；这是示例，按房间和镜头最近对焦距离调整。人物面部保持在画面内，不必追求同样步速。可用地面胶带标起点终点，有尺子才记录测得距离；否则填“约值”或留空。

让人物先面对镜头停 3 秒，再走近、停一下、退远。暗光组尽量同样路线、同样构图。一次出现拉风箱、框跳到背景或完全丢失时，继续录到恢复或结束，不要立刻删掉重拍。

### S05：横移与短暂遮挡

人物横向走过画面，在画面内停留。中途让第二个人举一块纸板短暂挡住脸或上半身约 1 秒，再移开；或使用既有前景物体。说明遮挡的是脸、上身还是全身。保留遮挡前后各数秒。不要让主体忽然冲向相机或在道路等危险环境测试。

首轮允许把横移和遮挡放在同一条视频里。扩展采集时应分开拍，便于分清“横移失败”与“遮挡恢复失败”。

### S06：手动对焦参考，不是自动对焦成绩

在与静物测试相同的光线、机位、焦段、光圈和曝光下，将拨杆置于 MF。先用放大显示找到看上去最清晰的位置，再围绕它拍约 7 张：略偏近的 3 张、认为最清晰的 1 张、略偏远的 3 张。每张小幅转动对焦环，目标是至少有几张跨过最佳焦点；幅度不用精确，但不要只拍 7 张明显虚焦图。

按照实际拍摄顺序记作 `mf_01` 到 `mf_07`，并说明顺序是“近→远”还是其他顺序。对于电子对焦环，“转了多少度”不能作为物理焦点移动量。研究人员之后挑选参考图；机主不必判断亚像素清晰度。

熟悉相机者可以额外用 **Bracketing → Focus Bracket** 生成参考，但须保存所有原片和步长/张数/顺序设置，并将其标为单独方法。自动包围的步长不是毫米或编码器刻度，不与手动序号混用。[DC-S5 官方高级说明书，pp. 156–160](https://eww.pavc.panasonic.co.jp/dscoi/DC-S5/P_PP/DC-S5_DVQP2197ZD_full_eng.pdf)

## 5. 试采通过后再扩展

研究人员先检查原始文件是否齐全、手机是否看清 LCD、编号能否对应、静物参考是否确实跨过清晰点。通过后再做下面的可比数据，避免先拍几千张才发现配置不合适。

| 测试 | 光线 | 每种光线的数量 | 扩展总量 |
|---|---|---|---|
| AFS 静物 | 正常、暗光、逆光 | 近端 5 + 远端 5 次 | 30 次，最多 30 对 RAW+JPEG |
| MF 参考 | 同上 | 7 张 | 21 对 RAW+JPEG |
| AFC 视频走近退远 | 同上 | 每条 15–20 秒，重复 2 次 | 6 条 |
| AFC 视频横移 | 同上 | 每条 15–20 秒，重复 2 次 | 6 条 |
| AFC 视频遮挡后重现 | 同上 | 每条 15–20 秒，重复 2 次 | 6 条 |

逆光表示光源主要在主体后方，仍要记录主体是否明显欠曝；不能把它和单纯暗光混成一类。各光线下保持人物、镜头、焦段、位置和动作尽量可比。每次改变焦段、镜头或 AF 模式都另起序列。

额外有帮助但不是第一轮必需的内容：侧脸和转身、两人交叉、主体离开后重新进入、空场景误检、背景上有人脸图案。如果主人愿意，也可以另拍宠物或鸟类；动物检测开关、动物类别与镜头必须单独记录，不强求机主寻找动物或人为惊扰它们。

普通 Tracking 模式与 Face/Eye/Body/Animal Detect. 是不同条件。需要比较时用相同场景分两组拍，明确标模式，不能把切换前后当成同一连续测试。视频结果也不能直接当成“连拍照片的 AFC 成功率”；若要研究移动照片，另加普通 AFC 单张或连拍组并保存各原片。

使用项目工具创建的会话目录，示意如下；`<session_id>` 是匿名编号，例如 `s5_owner01_20261127`，不用真实姓名：

```text
sessions/<session_id>/
  session.json
  sequences.json
  events.csv
  raw/
    S01_static_normal/
      camera/  原始 RW2、JPG
      phone/   手机拍 LCD 的视频
    S02_static_low/
      camera/
      phone/
    S03_approach_normal/
      camera/  相机原始视频
      phone/   对应手机视频
    S04_approach_low/
      camera/
      phone/
    S05_lateral_occlusion/
      camera/
      phone/
    S06_manual_reference/
      camera/  两种光线的原始 RW2、JPG
      phone/   有则保留
```

不会运行工具或填写 JSON 也没关系：先按编号分文件夹，附一份手机备忘录或纸笔拍照，由研究人员录入。**不要为了满足格式编造设置。** JSON 中未知值用 `null`；表格中可空白并注明原因。

每次会话至少记录：机型/固件、镜头/固件、焦段、日期与时区、照片和视频设置、匿名机主编号；每个序列记录光线、AF 模式/连续 AF 设置、动作、起点方法、相机与手机文件的对应关系、有哪些意外情况。每次重复要能区分，记录“近端 1”“远端 1”等。设置更改时拍一张设置照片并写明从哪条序列开始生效。

原始文件名请保留。如两张卡或两台设备出现同名文件，按设备或卡分别建子目录，**不要覆盖**。RAW 与 JPEG 以同一相机文件名配对；不要只交相机屏幕的照片，也不要只交剪辑或导出的视频。

传输前抽查能否打开，再用 ZIP 等方式打包原目录。通过与项目负责人约定的私密链接或私密存储交接，不要发到公开 GitHub issue、公开网盘或仓库。原片上传到公开代码仓库不是本项目流程。保留原卡或一份本地副本，待对方核对收到后再处理。

## 7. 交接前检查单

- [ ] 确认是 DC-S5，并记录版本与镜头；不是根据文件夹名字猜机型。
- [ ] S01/S02 有配对 RAW+JPEG；失败/超时也有记录。
- [ ] S03–S05 有相机原视频和对应手机 LCD 视频，编号可对应。
- [ ] S06 的光线与对应静物组一致，参考组中至少有看上去接近最佳焦点的照片。
- [ ] 设置、近/远重置方法、光线描述、重复编号有记录。
- [ ] 原始文件未修图、剪辑、重编码或经聊天软件压缩；文件名未被覆盖。
- [ ] 人像参与者了解用途并同意私下交给研究人员；公开使用需要另行确认。
- [ ] 缺项与不知道的值都标明了；没有把估计值冒充实测值。

## 8. 研究人员收到后做什么

研究人员负责校验文件、读取可用 EXIF、对齐两路视频、标注目标框/遮挡/身份、选择清晰参考、划分训练与验证数据。机主不用给成千上万帧画框。

评估时分开统计“屏幕显示检测到”“框是否跟到正确主体”“照片/视频是否实际合焦”；不能用绿框自动生成“合焦真值”。AFS 触发到可见提示的时间仅是手机视频上的近似观测，须记录帧率与测量不确定性。来自同一人物、同一路径或同段视频的相邻帧不应随意分进训练集和测试集，以免结果虚高。

这些数据能支持外部行为评估、训练样本准备和改进目标识别实验。它们**还不能单独证明拆出的模型与 S5 原机网络一致，也不代表已经恢复完整 DFD 或镜头控制闭环**。

只有以后获得可授权使用的 SDK、模拟器或可靠开发接口，才考虑另一个高级采集任务：同一输入对应的原机输出张量、准确预处理与量化参数、固件版本及张量校验值，以及带时钟说明的镜头/传感器遥测。高级任务不要求普通机主自行开调试口或刷实验固件，本指南不依赖这些条件。
