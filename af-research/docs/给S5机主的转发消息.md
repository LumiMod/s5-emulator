# 给 S5 机主的转发消息

想请你帮忙采一点 **松下第一代 LUMIX DC-S5** 的对焦样本，用来研究主体识别、连续跟焦，以及静物和弱光下的对焦表现。

**只用相机正常拍摄功能。不用刷固件、拆机、进维修模式，也不用安装不明程序。** 用你现有的自动对焦镜头、手机和一个稳定支撑即可。

先做一轮约 15 分钟的试采，确认文件能用，再决定要不要多拍：

1. 拍几张相机设置页面：机身/镜头型号和版本、照片画质、对焦模式、视频设置。
2. 对同一个静止、有纹理的物体，在正常光和较暗光线下，分别拍 6 次自动对焦照片，保存 **RAW+JPEG**。每次先把焦点移近或移远，再重新对焦；失焦照片也保留。
3. 拍 3 段约 15 秒的视频：正常光走近走远、暗光走近走远、正常光横向移动并短暂被遮挡。相机保存原视频；同时用手机对着相机屏幕录像，拍到对焦框的变化。
4. 对静物补拍两组手动对焦参考，每组约 7 张，焦点从略近到略远。

不用你给每一帧画框，也不用知道“镜头编码器”“内部张量”是什么。没有照度计就不填 lux；不确定的设置拍张照片就行。

请保留原始文件名和文件，不修图、不删失败样本、不用聊天软件压缩发送。拍到的人先取得同意。原片通过我们约定的**私密传输方式**交接；公开 GitHub 只放工具和说明，不放人像原片或个人信息。

详细操作见同目录《S5机主采集指南》。如果时间不足，先交正常光静物、走动视频和设置照片也有帮助；其余标成未采集即可。

这些样本可以帮助我们评估和准备训练数据，但不能直接读取相机内部网络输出，也不能证明电脑上的模型已经与原机完全一致。
